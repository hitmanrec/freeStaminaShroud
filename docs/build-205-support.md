Из загруженного `new-build-report.tar.gz` проверен отчёт текущего EXE:

- SHA-256: `ce6fdba63e27744943b695921383a29133285d359e07671f6ca33a47e2147618`;
- CodeView GUID little-endian: `e378da3d6079c049b30cd1604a0e7846`, age 205;
- дизассемблирование завершено, пропущенных функций нет.

Сам EXE, его фрагменты и дизассемблирование в Git не добавлены.

## Результат сравнения

Система спринта сохранила RVA `0x2f1000`, точка накопления — `0x2f1505`,
возврат — `0x2f150d`. Пролог, размер/выравнивание стека, загрузка селектора
R14D из `DynamicLocomotion+0x59` в `0x2f1121`, загрузка RAX из `[rbp-0x68]`
в `0x2f1501` и восемь байт ADDSS/MOVSS не изменились. Регистры и локальные
ветвления проверенной функции совпадают; отличающиеся байты относятся к
смещениям CALL и RIP-relative ссылок на данные. Перемещённые данные функция
по-прежнему читает сама, патч их не интерпретирует и не подменяет.

Observer в `0x21fbc0` сохранил пролог и передачу четырёх аргументов: RCX —
атрибут, RDX — registry, R8D — delta, R9D — root. Адреса внутренних вызовов
изменились; detour их не использует и передаёт вызов оригиналу.

## Runtime-проверки

В `probe/builds.h` две явные записи:

| Сборка | Допустимый режим таблицы |
| --- | --- |
| `69f0e9573b32c24a8838d3fff550824c` / 520 | EXACT |
| `e378da3d6079c049b30cd1604a0e7846` / 205 | EXACT или PATTERNS |

PATTERNS не разрешён для всех неизвестных сборок. Серверный EXE, изменённые
GUID/age и прочие режимы таблицы отклоняются. Дополнительно остаются проверки
диапазона .text, адреса системы, пролога и байтов точки патча.

Добавлен FNV-1a digest полного диапазона спринта `[0x2f1000, 0x2f15b3)` —
1459 байт, включая все три связанных .pdata-фрагмента. Проверенные значения:
`0xc01aa88c` для /520 и `0x40862718` для /205. Это дополнительный детектор
изменения машинного кода, не криптографическая проверка подлинности EXE.
Неожиданное изменение даёт `sprint_patch_body status=3`; обходить его не нужно.
Наличие новой точной таблицы загрузчика для /205 не требуется для этих двух
проверенных точек, но предупреждения E1005 о других функциях загрузчика
могут остаться. Совместимость этих других функций здесь не обещается.

## Проверка

Пройдены все native тесты и Python-тесты, сборка DLL через Zig 0.14.1.
Добавлены регрессии допуска именно /205 PATTERNS, отказа для неизвестных
fingerprint/age/стороны/режима и изменённого тела функции. Отдельный native
harness прочитал байты из обоих предоставленных отчётов: принял правильную
пару сборка/код, отверг перекрёстную пару и изменение инструкции загрузки
селектора. Архив использован только как данные для сравнения и проверки.

Игра/Proton в облаке не запускались. Для следующего прогона обновить исходники,
пересобрать и переустановить DLL с `--replace` при полностью закрытой игре.
Сначала открыть мир одному: в свежем логе должны быть `probe=0.4.4`,
`sprint_patch_registered status=0`, а во время безопасного спринта —
ненулевой `skipped_sprint_adds`. Только после этого приглашать гостей и
выполнить [совместную проверку](guest-test.md). Гостям мод пока не ставить.
