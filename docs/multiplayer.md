# Игра с гостями

[← Главная](../README.md)

## Установка только у хоста

Хост устанавливает мод и открывает мир с возможностью подключения игроков.
Для первой проверки гостю **ничего устанавливать не нужно**: спринт, прыжки,
топор и подтверждённая кирка уже проверялись в таком режиме.

Серверный лог показывает авторитетные значения, а интерфейс гостя может
использовать собственное предсказание. В проверенных сессиях наблюдения гостя
совпали с эффектом мода; совместимость всех действий и сетевых условий не заявляется.

## Разрешить вход без Enshwick

Enshwick по умолчанию может требовать загрузчик у гостей. После первого
открытия мира закройте игру и найдите рядом с сохранением файл:

```text
<save>-mod-settings/enshwick/enshwick.toml
```

Измените в нём:

```toml
require_enshwick = false
```

Сохраните остальные параметры. Это файл выбранного мира, а не папки установки
игры. Расположение сохранений зависит от Steam Cloud и Proton-prefix.
После изменения снова откройте мир и пригласите гостя.

Если подключение не удалось, сохраните сообщение об ошибке и лог хоста.
Установка загрузчика гостю изменит условие проверки «мод только у хоста».

## Короткая проверка после обновления

1. Хост открывает мир один, стоит несколько секунд; затем подключается гость.
2. В безопасном месте каждый по очереди спринтит, делает двойной прыжок
   и работает инструментом. Второй игрок в это время стоит.
3. Для проверки независимости боя один привлекает врага, другой остаётся
   достаточно далеко. У участника боя передвижение должно иметь обычную
   стоимость; у второго — оставаться бесплатным.
4. После ухода от врага подождите хотя бы 10 секунд без боевой цели/попаданий.
5. При проверке возрождения погибает только один: ресурсы другого игрока
   не должны пополняться от этого события.

Прогон можно сократить до механики, которую вы проверяете. Для диагностики
полезны порядок действий и наблюдения гостя: падал ли его индикатор, мог ли
он продолжать спринт. Видео не обязательно, но помогает сравнить интерфейс
с серверными значениями.

## Как различить игроков в логе

`sprint_player slot=… entity=…` связывает слот и персонажа. Если хост вошёл
первым, его запись видна до подключения гостя. Номер слота сам по себе
не доказывает роль хоста.

- `skipped>0` — реальные пропуски расхода спринта этого игрока.
- `cost_trace … applied_delta=0` — подавление прямого расхода прыжка/инструмента.
- `stamina_status` — серверный запас по entity.
- `respawn_refill` — однократное восстановление трёх ресурсов указанного игрока.
- `loader_channel_status=1` — готового канала Enshwick нет; это ожидаемо у гостя
  без загрузчика. Значение 0 подтверждает канал, но не установку именно этого мода.

Подробнее о значениях и сборе файлов — в [диагностике](troubleshooting.md).
