# Игровые правила

[← Главная](../README.md)

## Передвижение и бой

Спринт, двойные прыжки и наземные прыжки на склонах бесплатны **вне обнаруженного
боя**. Обычный прыжок, который уже бесплатен в игре, не получает отдельного расхода.

Бой определяется отдельно для каждого игрока:

- ИИ выбрал игрока в `SelectedTargets[0]` — выбранную боевую цель.
- Игрок получил попадание либо нанёс попадание сущности с компонентом Faction.
- После последней такой цели или попадания действует задержка **10 секунд**.

Обычные наблюдения ИИ из других элементов массива и события лечения сами
по себе не запускают задержку. Опрос целей выполняется раз в 250 мс.
Это детектор по наблюдаемым событиям и выбору цели, а не универсальный
штатный флаг боя: у отдельных существ возможны отличия.

При неполных данных, неизвестном типе действия или истёкшем разрешении
сохраняется обычная стоимость. Планер, плавание и прочие действия не входят
в правило бесплатного наземного передвижения.

При повторных двойных прыжках запас не уменьшается, но восстановление может
приостанавливаться. Это поведение принято как некритичное и оставлено как есть.

## Инструменты

Топор для рубки и подтверждённая кирка работают бесплатно **независимо от боя
и цели**: дерево, руда, земля, существо или взмах в воздух.

Текущее определение инструмента:

- Для общего правила проверяются текущая категория предмета Tools и анимация
  TwoHanded. Оно может охватывать другие инструменты с теми же признаками.
- Кирка с подтверждённым ресурсным item ID `2671192505` распознаётся явно.
  Это постоянный ID предмета, а не временный ID сущности в сохранении.
- Другие варианты кирок, не подходящие под общее правило, отдельно не подтверждены.

Предмет проверяется в момент списания. Боевые предметы категории Weapons
не становятся бесплатными только из-за двуручной анимации. В исследованных
сессиях остался предмет `1397467393` с зависящей от анимации классификацией;
его назначение и поведение нужно проверить отдельно. Поэтому совместимость
всех предметов игры не заявляется.

## Возрождение

После подтверждённой смерти и оживления **здоровье, стамина и мана** однократно
заполняются до текущих максимумов персонажа.

Мод ждёт положительного здоровья, выхода из режима смерти и одинаковых
максимумов на двух последовательных опросах. Обычно пополнение происходит
через 250–500 мс после готовности персонажа. Каждый игрок обрабатывается отдельно,
в том числе при смене entity ID во время возрождения.

Последующий урон и расходы работают обычно. Вход в мир, переподключение
и телепортация сами по себе не дают пополнения. Выход игрока отменяет ожидание.
Если доступ к ресурсам не восстановился в течение 10 секунд после появления
готового живого персонажа, попытка отменяется и записывается в лог.

Используются `PLAYER_DIED` и, для распознанного игрока, `EntityDiedEvent`.
Некоторые причины смерти могут отсутствовать в журнале загрузчика; если игра
не прислала ни одного распознанного события, пополнение не запускается.
Поднятие союзником без предшествующего подтверждения смерти отдельно не проверено.

## Что проверено

| Сценарий | Результат |
| --- | --- |
| Длительный спринт вне боя | Проверен хостом |
| Возврат расхода при агрессии волков до первого попадания | Проверен хостом |
| Двойные и горные прыжки, топор, подтверждённая кирка | Проверены хостом и гостем |
| Гость без установки мода/загрузчика | Проверен для перечисленных действий |
| Восстановление при возрождении | Подтверждено пользователем на 0.6.0 |
| Разные игроки и максимумы, повторное возрождение, отсутствие постоянного лечения | Проверены native-тестами |
| Изолированный бой одного из двух игроков | Отдельная игровая проверка ещё нужна |
| Все враги, предметы, нативная Windows, headless сервер | Полная проверка не проводилась |
