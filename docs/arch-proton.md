# Gameplay Preview 0.5.2: Arch Linux / Proton

Эта версия добавляет бесплатные наземные прыжки вне наблюдаемого боя и
действия двуручных инструментов независимо от боя, сохраняя патч спринта.
[Точные правила, ограничения и игровой тест 0.5.0](action-preview.md).
Планер и плавание сохраняют обычный расход.
Поддерживаются две проверенные сборки: CodeView
`69f0e9573b32c24a8838d3fff550824c` / age 520 (EXACT) и
`e378da3d6079c049b30cd1604a0e7846` / age 205 (EXACT или PATTERNS).
Другие сборки и непроверенный код отклоняются. Подробнее —
[поддержка новой сборки 0.4.4](build-205-support.md).

Это экспериментальная версия; Enshrouded/Proton в облаке не запускался.
Подробнее об ограничениях детектора боя — [здесь](sprint-preview.md).
Сначала проверяйте в одиночном мире через Host. Перед установкой сохраните
резервную копию мира. Обновлять и удалять DLL нужно при полностью закрытой игре.

## 1. Подготовка и сборка

Закройте игру. Команды выполняются обычным пользователем; `sudo` нужен только
для системных пакетов. Это инструкция для обычного Steam, не Flatpak Steam.
В Flatpak потребуется отдельно разобраться с доступом к библиотеке и путями.

```sh
sudo pacman -S --needed base-devel zig python git
git clone https://github.com/hitmanrec/freeStaminaShroud.git
cd freeStaminaShroud
sh scripts/test-all.sh
sh scripts/build-probe.sh
```

Если репозиторий уже скачан, перейдите в его папку и обновите его обычным
`git pull --ff-only`, сохранив собственные изменения. Скрипт можно запускать
и из другого каталога по абсолютному пути.

Результат: `.build/probe/hitmanrec.stamina-probe/stamina_probe.dll` и её
`SHA256SUMS`. Zig выполняет кросс-компиляцию, Windows SDK/Wine для сборки
не нужны. В облаке проверен Zig 0.14.1; версия пакета Arch может отличаться.
Можно указать другой установленный Zig:

```sh
ZIG=/полный/путь/к/zig sh scripts/build-probe.sh
```

Заголовок SDK и MIT-лицензия включены в репозиторий; его контрольная сумма
проверяется перед сборкой. Сама сборка мода не скачивает зависимости.

## 2. Загрузчик Enshwick

```sh
python3 scripts/download-probe-loader.py
```

Скрипт скачивает официальный архив и проверяет SHA-256 именно исследованной
сборки `535efb4944f99b84de6c5cd12378042b0485d3dc`:
`f6ceb5b93bf0e659f95e1f75b67c578b38b6ac1b510a0027999380e2ab3de7ec`.
Адрес upstream `dev` изменяемый. Если скрипт сообщает об изменении архива,
**не меняйте ожидаемый хеш и не отключайте проверку**: нужна проверенная новая
пара loader/SDK или сохранённый архив этой сборки. Даже совпавшая ABI не
гарантирует поддержку более новой версии игры.

## 3. Установка

Steam → Enshrouded → Properties → Installed Files → Browse: найдите каталог
с `enshrouded.exe`. Для стандартной библиотеки это обычно:
`~/.local/share/Steam/steamapps/common/Enshrouded`. Используйте реальный путь,
если библиотека расположена на другом диске.

```sh
GAME_DIR="$HOME/.local/share/Steam/steamapps/common/Enshrouded"
python3 scripts/install-probe.py --game-dir "$GAME_DIR" \
  --loader-zip .build/enshwick.zip --dry-run
python3 scripts/install-probe.py --game-dir "$GAME_DIR" \
  --loader-zip .build/enshwick.zip
```

Скрипт устанавливает только:

```text
Enshrouded/
  powrprof.dll
  mods/
    enshwick/enshwick.dll
    hitmanrec.stamina-probe/stamina_probe.dll
```

Остальные файлы архива не распаковываются. Скрипт проверяет архитектуру DLL,
отказывается писать через симлинки назначения и не перезаписывает отличающиеся
файлы. Одинаковая повторная установка ничего не меняет. Для **осознанного**
обновления добавьте `--replace`: старые файлы сохранятся в
`Enshrouded/.stamina-probe-backups/<UTC timestamp>/`. Если `powrprof.dll` уже
принадлежит другому загрузчику, не заменяйте его без проверки совместимости.
Если подходящий Enshwick уже установлен, можно опустить `--loader-zip`.

В Steam → Properties → General → Launch Options добавьте:

```text
WINEDLLOVERRIDES="powrprof=n,b" %command%
```

Если уже есть launch options или другие DLL overrides, объедините их вручную,
сохранив необходимые параметры. Не заменяйте существующую строку вслепую.

## 4. Первый запуск и проверка

Включите **Free Stamina Shroud - Gameplay Preview** в меню Mods и откройте мир
через Host. В логе источника `hitmanrec.stamina-probe` должны быть:

```text
probe=0.5.2 read_only=false sprint_preview=true ...
sprint_patch_registered status=0
sample ... sprint_free_mask=1 ai_complete=1 skipped_sprint_adds=...
```

Регистрация патча сама по себе ещё не подтверждает его выполнение.
`skipped_sprint_adds` больше нуля во время спринта подтверждает пропуск
списаний; это число с прошлого опроса, а не сумма за всю игру.
`sprint_free_mask=1` разрешает спринт игроку в слоте 0; для других слотов
это битовая маска. При `ai_complete=0` бесплатный спринт блокируется.
Если появляется `sprint_patch_guard`, `sprint_patch_site` или
`sprint_patch_prologue` с ошибкой, проверку не обходите: сохраните лог.

В 0.4.4 добавлена поддержка новой сборки игры. В 0.4.3 исправлена блокировка из-за небоевых элементов SelectedTargets и
добавлена отдельная диагностика каждого игрока. Для текущего совместного
прогона используйте [сценарий с гостем без мода](guest-test.md).

Для прыжков и инструментов используйте [новый сценарий 0.5.0](action-preview.md).
Ниже — отдельная проверка спринта:

1. Загрузитесь в безопасном месте, постойте секунду и спринтите 10–15 секунд.
   Стамина не должна уменьшаться от спринта.
2. Сделайте двойной прыжок: вне боя его расход должен быть обнулён.
3. Подойдите к врагу, дайте ему выбрать вас целью, получите удар и попробуйте
   спринт. При обнаруженном бое расход должен стать обычным.
4. Уйдите от врага. После исчезновения его цели и последнего попадания
   подождите не меньше 10 секунд: бесплатный спринт должен вернуться.
5. Перезайдите в мир и повторите безопасный спринт.

Сохраните свежий лог из `Enshrouded/logs/` и результат этих пяти пунктов.
Ручные метки действий для первого теста не нужны. Сохраните также лог загрузчика,
если произошёл вылет или мод не включился.

Опрос целей ИИ идёт раз в 250 мс: начало агрессии может быть замечено с задержкой.
Цель ИИ ещё не доказывает бой, поэтому возможны лишние блокировки.
Менять включение мода в середине сессии пока не следует: закройте игру и
перезапустите её после изменения настройки.

## 5. Гости и Windows

Совместную проверку проводите с модом только у хоста, без установки на гостя.
Допуск гостя без загрузчика, подготовка и пошаговый сценарий описаны
в [guest-test.md](guest-test.md). Работа клиентского предсказания гостя пока
не подтверждена; серверные счётчики и его наблюдения нужно сопоставить.

Собирается Windows x86-64 DLL, которую Proton загружает как Windows-библиотеку.
Для нативной Windows используется та же DLL и соответствующий Enshwick;
отдельная Linux-библиотека не нужна. Нативная Windows также пока не проверена.

## Удаление

Закройте игру и перенесите `mods/hitmanrec.stamina-probe` за пределы `mods`.
Enshwick можно оставить. Для удаления самого загрузчика уберите установленный
`powrprof.dll` и `mods/enshwick/`, если другие моды от него не зависят, и удалите
только добавленный override из launch options. Сохранения не удаляйте; при
замене прежних DLL восстановите нужные файлы из резервной копии.

## Что проверено разработчиком

Native fake-host тесты реального C-кода, политика и установщик; исполняемый
тест обеих веток машинного перехода с Windows ABI callback на x86-64 Linux;
сборка через Zig 0.14.1 и четыре ABI-экспорта DLL. Новая DLL импортирует только
семь системных функций KERNEL32 (таймер и управление памятью), без CRT.
Игровую проверку выполняет пользователь по сценарию выше.
