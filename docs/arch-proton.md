# Диагностический мод: Arch Linux и Proton

Это **read-only диагностика**, а не готовый мод бесплатной стамины.
Он не меняет мир, расходы, характеристики или игровой combat state. Установка
добавляет загрузчик; тот создаёт собственные настройки/логи/метаданные мира.
Работает через C ABI Enshwick 11.1, Windows x86-64 DLL. Устанавливать сначала
только на компьютер, который открывает мир через Host, без других модов.

## 1. Подготовка и сборка

Закройте игру. Команды выполняются обычным пользователем; `sudo` нужен только
для системных пакетов. Это инструкция для обычного Steam, не Flatpak Steam.
В Flatpak потребуется отдельно разобраться с доступом к библиотеке и путями.

```sh
sudo pacman -S --needed base-devel zig python git
git clone https://github.com/hitmanrec/freeStaminaShroud.git
cd freeStaminaShroud
sh scripts/test-all.sh
sh scripts/build-probe.sh
```

Если репозиторий уже скачан, перейдите в его папку и обновите его обычным
`git pull --ff-only`, сохранив собственные изменения. Скрипт можно запускать
и из другого каталога по абсолютному пути.

Результат: `.build/probe/hitmanrec.stamina-probe/stamina_probe.dll` и её
`SHA256SUMS`. Zig выполняет кросс-компиляцию, Windows SDK/Wine для сборки
не нужны. В облаке проверен Zig 0.14.1; версия пакета Arch может отличаться.
Можно указать другой установленный Zig:

```sh
ZIG=/полный/путь/к/zig sh scripts/build-probe.sh
```

Заголовок SDK и MIT-лицензия включены в репозиторий; его контрольная сумма
проверяется перед сборкой. Сама сборка мода не скачивает зависимости.

## 2. Загрузчик Enshwick

```sh
python3 scripts/download-probe-loader.py
```

Скрипт скачивает официальный архив и проверяет SHA-256 именно исследованной
сборки `535efb4944f99b84de6c5cd12378042b0485d3dc`:
`f6ceb5b93bf0e659f95e1f75b67c578b38b6ac1b510a0027999380e2ab3de7ec`.
Адрес upstream `dev` изменяемый. Если скрипт сообщает об изменении архива,
**не меняйте ожидаемый хеш и не отключайте проверку**: нужна проверенная новая
пара loader/SDK или сохранённый архив этой сборки. Даже совпавшая ABI не
гарантирует поддержку более новой версии игры.

## 3. Установка

Steam → Enshrouded → Properties → Installed Files → Browse: найдите каталог
с `enshrouded.exe`. Для стандартной библиотеки это обычно:
`~/.local/share/Steam/steamapps/common/Enshrouded`. Используйте реальный путь,
если библиотека расположена на другом диске.

```sh
GAME_DIR="$HOME/.local/share/Steam/steamapps/common/Enshrouded"
python3 scripts/install-probe.py --game-dir "$GAME_DIR" \
  --loader-zip .build/enshwick.zip --dry-run
python3 scripts/install-probe.py --game-dir "$GAME_DIR" \
  --loader-zip .build/enshwick.zip
```

Скрипт устанавливает только:

```text
Enshrouded/
  powrprof.dll
  mods/
    enshwick/enshwick.dll
    hitmanrec.stamina-probe/stamina_probe.dll
```

Остальные файлы архива не распаковываются. Скрипт проверяет архитектуру DLL,
отказывается писать через симлинки назначения и не перезаписывает отличающиеся
файлы. Одинаковая повторная установка ничего не меняет. Для **осознанного**
обновления добавьте `--replace`: старые файлы сохранятся в
`Enshrouded/.stamina-probe-backups/<UTC timestamp>/`. Если `powrprof.dll` уже
принадлежит другому загрузчику, не заменяйте его без проверки совместимости.
Если подходящий Enshwick уже установлен, можно опустить `--loader-zip`.

В Steam → Properties → General → Launch Options добавьте:

```text
WINEDLLOVERRIDES="powrprof=n,b" %command%
```

Если уже есть launch options или другие DLL overrides, объедините их вручную,
сохранив необходимые параметры. Не заменяйте существующую строку вслепую.

## 4. Первый запуск и гости

Запустите игру, проверьте наличие **Stamina Combat Probe** в меню Mods и
откройте мир через Host. Если загрузчик не появляется, проверьте путь и
override; если мод отвергнут по ABI, не обходите проверку — нужна совместимая
версия SDK/loader. Строка `read_only=true` в логе подтверждает вызов init, а
строки `sample` — выполнение чтений. Одно наличие DLL этого не подтверждает.

Enshwick **по умолчанию требует Enshwick у гостей**. Для проверки именно
немодифицированного гостя нужно разрешить подключение без него: после первого
запуска закройте мир и в созданном файле
`<save>-mod-settings/enshwick/enshwick.toml` выставьте:

```toml
require_enshwick = false
```

Остальное содержимое файла сохраните. `<save>` — путь/имя сохранения выбранного
мира, а не папка установки игры. Найдите этот созданный файл рядом с сохранением
мира (каталог Steam Cloud или Proton-prefix зависит от вашей установки), затем
заново откройте мир. Это допускается для нашего диагностического server-side
мода; не переносите настройку на набор других модов без проверки их требований.
Гостю для диагностики не требуется наш мод. Изменение настроек допуска гостей
не доказывает, что будущий мод стамины сможет работать только у хоста.

## 5. Что собрать в лог

Логи Enshwick находятся в `Enshrouded/logs/`, отдельные файлы для источников.
Найдите свежий лог с ID `hitmanrec.stamina-probe` или строкой `read_only=true`.
Сначала собирайте данные в одиночку, затем с гостем без загрузчика/мода.

Выполните действия по отдельности и запишите время каждого:

1. Стойте спокойно, затем бегите и прыгните вне боя.
2. Достаньте оружие без врагов; уберите его.
3. Срубите дерево топором, добудьте руду киркой.
4. Подойдите к врагу: дождитесь агрессии **до первого попадания**.
5. Ударьте врага, получите удар; затем уйдите и дождитесь окончания боя.
6. Повторите с гостем: один игрок в бою, другой далеко от врагов.
7. Выйдите из мира и откройте его снова, чтобы проверить новые game/entity ID.

Пример формата (значения иллюстративные):

```text
probe=0.1.0 read_only=true loader=... binary_side=2 build_table=0 fingerprint_guid_le=... fingerprint_age=...
resolve keen::ecs::CombatStance.combatStanceEndTime status=0 offset=8 width=8 type_size=16
sample game=1 step=600 players_status=0 players=2
sample game=1 step=600 slot=0 entity=123 keen::ecs::CombatStance.combatStanceEndTime status=0 raw_le=...
```

`binary_side=2` означает EXE клиента, а не отсутствие встроенного сервера.
`build_table=0` — точная таблица, `1` — поиск по шаблонам. Сохраняйте fingerprint
для сопоставления сборки; мод не угадывает Steam build ID по приблизительному
номеру версии. `game` отличает открытия мира, `step` — шаг сервера, `slot` и
`entity` — игрока. Имена и ключи аккаунтов наш мод не пишет.

`status=0` означает успешное чтение/разрешение. `1` — отсутствующее поле или
компонент; `4` при разрешении — недопустимый диапазон; `7` — неправильный поток;
`8/9` — мир ещё не готов/отсутствует. Ошибки не превращаются в значения `false`.
`raw_le` — байты в порядке памяти little-endian: не готовый вывод «в бою».
Поля времени читаются как 8 байт без предположения о единицах, boolean как 1,
target ID/float-накопитель как 4, сетевой запас стамины как 2. Диапазоны
проверяются по отражению текущей сборки; смысл и типы полей ещё проверяются.
Клиентское `inCombatStance` может отсутствовать в серверном мире — это полезный
результат, а не повод читать память клиента по неподтверждённому адресу.

Снимки опрашиваются не чаще четырёх раз в секунду; пишутся изменения и
периодический снимок примерно раз в пять секунд. Короткие переходы между
опросами могут быть пропущены. Это диагностические кандидаты, не детектор боя.
Мод пока не подписывается на HitEvent и не определяет источник каждого расхода.
Неизменившаяся сетевая стамина также не доказывает отсутствие расхода.

Перед отправкой логов просмотрите их: сам загрузчик может записывать имена,
пути или другую информацию, даже если наш мод этого не делает. Для исследования
нужны стартовые `resolve`, fingerprint и фрагменты `sample` с описанием действий.

## Удаление

Закройте игру и перенесите `mods/hitmanrec.stamina-probe` за пределы `mods`.
Enshwick можно оставить. Для удаления самого загрузчика уберите установленный
`powrprof.dll` и `mods/enshwick/`, если другие моды от него не зависят, и удалите
только добавленный override из launch options. Сохранения не удаляйте; при
замене прежних DLL восстановите нужные файлы из резервной копии.

## Что проверено разработчиком

В Linux облачной среде выполнены native fake-host тесты реального C-кода,
unit-тесты политики и установщика, сборка Windows x86-64 DLL через Zig 0.14.1,
проверка четырёх ABI-экспортов и отсутствия импортов DLL. Официальный архив
загрузчика скачан и проверен по хешу. Сам Enshrouded/Proton здесь не запускался;
Arch-машина и подключение гостя требуют описанной выше проверки пользователем.
